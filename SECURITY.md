# Security Policy

## Supported Versions

This project is early. Security fixes target the latest public release.

## Reporting a Vulnerability

Please open a GitHub security advisory or contact the maintainer privately if the issue could expose private data, execute unexpected code, or affect generated runtime assets in a harmful way.

Do not use this project or its optional Studio plugin to scan, test, or modify codebases, systems, or repositories you do not own or have permission to review.

## Scope

In scope:

- Blender addon source code.
- Export helpers.
- Optional Roblox Studio post-processor plugin included in this repository.

Out of scope:

- Private games or projects that use exported assets.
- Third-party Blender or Roblox vulnerabilities.
- User-created models, textures, or scenes not included in this repository.
