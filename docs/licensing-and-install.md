# Licensing and Install Behavior

LuArch is distributed as an open-source Blender addon under GPL-3.0-or-later.

This repository does not include a commercial licensing runtime, unlock flow, activation server, trial mode, paid feature gate, or license-key requirement.

Expected install behavior:

1. Download the release zip.
2. Install it through Blender preferences.
3. Enable `LuArch`.
4. Use the addon from the `LuArch` 3D View sidebar tab.

The `LICENSE` file is the open-source software license. It is not an activation system.
