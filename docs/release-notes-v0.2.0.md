# LuArch v0.2.0

Initial public open-source preparation release.

## Included

- Blender 4.5+ addon package.
- Procedural low-poly tactical building generation.
- Deterministic presets and seed-backed variants.
- Selected-building edit/regenerate workflow.
- District/block generation support.
- Validation before export.
- FBX + RBXMX export support.
- Optional Roblox Studio post-processor plugin.
- Public README, docs, media, and release builder.

## Install

Download `luarch-v0.2.0.zip`, then install it from Blender:

```text
Edit -> Preferences -> Add-ons -> Install...
```

Enable `LuArch` and open the `LuArch` sidebar tab.
